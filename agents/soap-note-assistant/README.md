# SOAP Note Assistant

Transforms clinician dictations and visit transcripts into standardized SOAP progress notes with ICD-10 diagnosis and CPT code suggestions.

## Working Folder Structure

- Clinician Notes: `./dictations/`
- Progress Notes: `./notes/`
- Templates: `./templates/`

## Example Prompts

- "Convert the doctor's visit notes in ./dictations/patient_1042.txt into a complete SOAP note."
- "Suggest ICD-10 and CPT codes for this acute sinusitis visit."
- "Verify that physical exam findings in this note match the documented chief complaint."
