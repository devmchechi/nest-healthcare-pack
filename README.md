# Healthcare & Practice Ops Pack

Local, HIPAA-friendly operational intelligence for independent doctors, dentists, therapists, and clinic managers. Transforms clinical dictations into structured SOAP progress notes, drafts evidence-backed insurance claim denial appeals, and screens patient intake histories for critical contraindications—all running locally with zero cloud data transmission.

## Included Agents

- **SOAP Note Assistant (`soap-note-assistant`):** Converts clinician dictation notes into standardized SOAP progress notes with ICD-10 and CPT coding suggestions.
- **Claim Denial Appealer (`claim-denial-appealer`):** Analyzes insurance claim denial EOBs and drafts compelling appeal letters citing clinical justification.
- **Patient Intake Triager (`patient-intake-triager`):** Screens intake questionnaires to highlight allergies, drug interactions, and chronic conditions before patient exams.

## Included Workflow

- **Clinical Intake and Billing Audit (`clinical-intake-and-billing-audit`):** Screens incoming patient intake, generates compliant SOAP visit documentation, and prepares claim appeal packages.
