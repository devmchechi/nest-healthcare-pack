# Patient Intake Triager

Screens patient intake questionnaires to identify allergies, drug interactions, and chronic comorbidities, producing 1-page pre-exam provider briefs.

## Working Folder Structure

- Patient Intake Forms: `./intake/`
- Provider Briefs: `./briefs/`
- Safety Protocols: `./protocols/`

## Example Prompts

- "Screen the patient intake questionnaire in ./intake/patient_993.txt for drug interactions."
- "Prepare a 1-page provider summary highlighting allergies and chronic conditions."
- "Are there any contraindications between this patient's current medications and a planned minor surgery?"
